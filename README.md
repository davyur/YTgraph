# 📊 Графики из Excel — Flask-приложение для визуализации данных

Веб-приложение на **Flask** для построения интерактивных графиков: загрузка табличных данных из Excel, ввод аналитических функций и визуализация с помощью **Plotly**. Приложение поддерживает несколько режимов работы — от простой визуализации таблиц до ручного ввода точек и аппроксимации.

---

## ✨ Функционал

### 📁 Загрузка данных из Excel (`/`)
- Загрузка одного или нескольких файлов `.xlsx` / `.xls`
- Автоматическое определение столбцов и построение графиков по данным
- Наложение нескольких наборов данных на один график (до 50 функций)
- Построение аппроксимирующих кривых поверх исходных данных

### 🧮 Аналитический анализ (`/analytical`)
- Ввод математических выражений в свободной форме (поддержка `sin`, `cos`, `tan`, `exp`, `log`, `sqrt`, тригонометрия, гиперболические функции и др.)
- Автоопределение типа функции:
  - **Явная** — `y = f(x)`
  - **Параметрическая** — `x(t), y(t)`
  - **Полярная** — `r(θ)`
  - **Неявная** — уравнение с `x` и `y`
- Оператор `^` для возведения в степень, константы `pi` и `e`
- Галерея готовых примеров функций
- Настройка диапазонов осей X / Y / t и автомасштабирование

### 📈 Только функции (`/functions_only`)
- Массовое построение до **50** аналитических функций на одном графике
- Индивидуальные цвета из палитры (30 цветов) и подписи

### ⌨️ Ручной ввод данных (`/manual`)
- Построение графика по точкам, введённым вручную
- Экспорт собранных данных в файл (`/download_manual_data`)

### 📐 Аппроксимация
- **Полиномиальная** аппроксимация (произвольная степень, метод наименьших квадратов через `numpy.polyfit`)
- **Логарифмическая** аппроксимация вида `y = a·ln(x) + b`
- Отображение формулы аппроксимации на графике

### 📖 Инструкция (`/instruktion`)
- Встроенная страница с руководством по работе с приложением

## 🛠 Технологический стек

| Компонент      | Технология                          | Назначение                                  |
|----------------|-------------------------------------|---------------------------------------------|
| Язык           | Python 3                            | Основная логика приложения                  |
| Веб-фреймворк  | Flask                               | Маршрутизация, обработка форм и сессий      |
| Данные         | Pandas                              | Чтение и обработка Excel-файлов             |
| Математика     | NumPy                               | Вычисления, полиномиальная регрессия        |
| Визуализация   | Plotly (graph_objects)              | Интерактивные графики в HTML                |
| Шаблоны        | Jinja2 (HTML)                       | Клиентская часть (`templates/`)             |
| Загрузка файлов| Werkzeug `secure_filename`          | Безопасная обработка имён файлов            |

### Структура проекта

```
.
├── main.py              # Основное приложение (маршруты, вычисления, plotting)
└── templates/
    ├── index.html           # Главная: графики из Excel
    ├── analytical.html      # Аналитический анализ функций
    ├── functions_only.html  # До 50 функций на одном графике
    ├── manual.html          # Ручной ввод данных
    ├── simple.html          # Простой график из Excel
    └── instruktion.html     # Инструкция пользователя
```

## 🚀 Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/davyur/YTgraph.git
cd YTgraph

# 2. Создайте виртуальное окружение (рекомендуется)
python -m venv venv
source venv/bin/activate   # Linux/macOS
venv\Scripts\activate      # Windows

# 3. Установите зависимости
pip install flask pandas numpy plotly openpyxl

# 4. Запустите приложение
python main.py
```

Приложение будет доступно по адресу: **http://localhost:5000**

## ⚙️ Конфигурация

- Папка загрузок: `uploads/` (создаётся автоматически)
- Секретный ключ сессий: `app.secret_key` — **обязательно замените** перед продакшен-развёртыванием
- Режим отладки: `debug=True` (для разработки; в продакшене используйте gunicorn/uWSGI)
