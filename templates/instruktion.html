📖 Инструкция

🆕 Новое: Автоопределение типа функции + до 50 функций + выбор цвета!
🤖 Автоопределение: Программа сама определяет тип функции по выражению!
Просто введите формулу — система поймёт, что это: y=f(x), x=f(y), параметрическая, полярная или неявная.

📁 Файлы

  • Формат: .xlsx
  • Столбец 1 = X, Столбец 2 = Y
  • Главная: до 20 файлов
  • Аналитика: до 10 файлов
  • Пустые строки автоматически игнорируются

🧮 Типы функций (Автоопределение)

1. y = f(x) - Стандартная функция
Примеры: sin(x), x**2, exp(-x)
Используйте переменную x
2. x = f(y) - Обратная функция
Примеры: y**2, sin(y), sqrt(y)
Используйте переменную y (без x)
3. Параметрическая - x = f(t), y = g(t)
Примеры: cos(t) + sin(t) (окружность)
Используйте переменную t + второе поле
4. Полярная - r = f(θ)
Примеры: sin(3*theta) (роза), theta (спираль)
Используйте переменную theta
5. Неявная - f(x,y) = 0
Примеры: x**2 + y**2 - 1 (окружность), (x**2 + y**2 - 1)**3 - x**2*y**3 (сердце)
Используйте переменные x и y
  • Доступные функции: sin, cos, tan, exp, log, sqrt, abs, arcsin, arccos
  • Константы: pi, e
  • Степень: x**2 (не x^2)

🎨 Выбор цвета

  • 30 цветов в палитре
  • Каждая функция может иметь свой цвет
  • Выбирается в выпадающем списке

📏 Автомасштабирование

  • График автоматически подстраивается под функции
  • Можно задать свои диапазоны X, Y, T
  • T - параметр для параметрических функций

📈 Аппроксимация

  • Полиномиальная: степень 1-5
  • Логарифмическая: y = a·ln(x) + b
  • Отображается пунктиром поверх данных
  • Доступна для файлов и ручного ввода

💾 Экспорт

  • Скачивание данных в .xlsx (ручной ввод)
  • Экспорт графика: PNG, JPEG, SVG, PDF, HTML (через меню Plotly)
  • Иконка камеры в правом верхнем углу графика
